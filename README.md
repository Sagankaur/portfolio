# Sagandeep Kaur Portfolio

This repository contains Sagandeep Kaur's portfolio site.

## Vercel deployment

The deployable Next.js app is in:

```text
next-portfolio
```

When importing this repository into Vercel, set **Root Directory** to `next-portfolio`.
Vercel should then detect the Next.js app automatically.

## Local development

```bash
cd next-portfolio
npm install
npm run dev
```

Open `http://localhost:3000`.
